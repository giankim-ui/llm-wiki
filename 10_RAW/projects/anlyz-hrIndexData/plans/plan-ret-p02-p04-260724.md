- 차트는 **별도 파일** `"use client"`, 페이지에서 `dynamic(() => import(...), { ssr:false, loading })`, 컨테이너에 **명시적 height**(예 320px). ECharts option은 인라인 작성(테마 래퍼 없음).
- 에러/로딩은 p.01처럼 조기 반환.

### B-4. 데이터 계약 — `lib/data/types.ts` stub 3종 교체
현재 `{[key:string]:unknown}` placeholder. 실 JSON 실측 기준으로 확정:
```ts
export interface RetentionOrgRankRow { month:string; 부문명:string; 본부명:string; 팀:string;
  headcount_avg:number|null; leaver_count:number; rate_pct:number|null }
export interface RetentionByTraitRow { month:string; scope:"company"|"bu"; scope_id:string;
  trait_type:"job"|"grade"|"tenure"; trait_key:string; headcount:number|null; leaver_count:number; rate_pct:number|null }

  reason_group:string; leaver_count:number; share_pct:number }
```

### B-5. provider 신규 getter (`lib/data/provider.ts`)
기존 `getMonthly` 패턴(모듈 스코프 promise 메모이즈 → filter → month 오름차순 sort) 그대로:
- `getOrgRank(month: string, 부문명?: string): Promise<RetentionOrgRankRow[]>`
- `getByTrait(scope, scopeId, traitType): Promise<RetentionByTraitRow[]>`
- `getReasons(scope, scopeId): Promise<RetentionReasonRow[]>`
**UI는 provider만 import** — JSON 직접 fetch 금지(Phase2 Supabase 교체 seam).

### B-6. 재사용 헬퍼 (`lib/data/compute.ts` — 신규 작성 금지, 있는 것 사용)

`HIDDEN_OPTIONS = {NA MBU, 중국 SBU, 일본 SBU}` — `FilterBar.tsx`의 상수 재사용.

### B-7. 가드레일 (gotchas.md 기반 — 위반 시 하드 스톱)
1. **null rate 가드 필수**: 모든 tooltip/label formatter가 `null|undefined` 체크 후 `toFixed`. org 팀행 70%가 null → 회색·`-`·empty state.
2. **coverage 가시화**: 조인·필터 실패 행을 조용히 버리지 말 것. '기타' 버킷에 집계하고 **개수/커버리지% 노출**.
3. **BU 스코프 권위**: 사업단위는 `meta.부문명_list_latest_snapshot`만. 조직명 텍스트로 BU 추정 금지.
4. **정규직만**: `meta.scope_note`("사원범주=정규만 포함") 캡션 유지.
5. **신성장 SBU** 2026-01~06 proxy → 세부 grain headcount null(가드로 자연 처리).
6. **퇴직률 정의**: `leaver_count / headcount_avg × 100`. 캡션 "퇴직률은 월초·월말 평균 재직자 수 기준".
